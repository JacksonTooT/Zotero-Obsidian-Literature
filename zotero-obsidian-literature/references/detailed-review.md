# Detailed review structure

Write a source-grounded Chinese Markdown review with these sections:

- 一句话结论
- 研究背景与知识缺口
- 核心科学问题与假设
- 数据与研究对象
- 方法与分析流程
- 主要结果
- 作者如何解释结果
- 科学贡献
- 局限性与适用边界
- 值得进一步追问的问题
- 证据定位

Use tables only for genuinely repeated comparisons. Distinguish author claims from your synthesis. Include section names or page cues when the extracted text preserves them; never invent locators. State prominently if the review is abstract-only.
